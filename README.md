# SQL Data Engineering Foundations

## Project Overview

This project demonstrates foundational SQL and relational data
engineering concepts using a fully synthetic retail banking dataset.

The project models fictional customers, accounts, bank branches and
transactions and uses SQL to answer analytical business questions.

## Objectives

The project will progressively demonstrate:

- Relational data modelling
- SQL filtering and aggregation
- Joins
- CASE expressions
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- Data validation

## Dataset

All data used in this project is synthetic and does not contain real
customer or employer information.

The model contains four entities:

- Customers
- Accounts
- Branches
- Transactions
